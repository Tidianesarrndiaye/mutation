# Mutation

> Une application qui permet aux personnes **non parlantes** et **sourdes** de communiquer entre elles (et avec les autres) dans **un langage commun, plus expressif que les signes seuls**.

**Statut : phase de cadrage / documentation.** Aucun code pour l'instant. Les choix techniques seront discutés dans un second temps.
