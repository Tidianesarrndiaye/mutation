# Mutation

> Une application qui permet aux personnes **sourdes** et **non parlantes** de communiquer dans un langage commun, plus expressif que les signes seuls : soit un langage gestuel simplifié, soit les langues des signes existantes avec un interprète IA (caméra → voix, parole → avatar 3D).

**Statut : phase de cadrage / documentation.** Aucun code pour l'instant. Les choix techniques seront discutés dans un second temps.
